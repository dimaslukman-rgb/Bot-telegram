# Telegram Reporting Bot

An open-source Telegram bot designed to automate reporting and notifications for small businesses and operational teams.

This project helps users send scheduled reports, receive alerts, and monitor important information directly through Telegram.

## Features

- Daily reporting notifications
- Scheduled report delivery
- Custom Telegram message templates
- Easy configuration
- Lightweight and beginner-friendly
- Ready to integrate with Google Sheets and automation tools

## Use Cases

This bot can be used for:

- Small business reporting
- Sales reporting
- Operational monitoring
- Attendance reports
- Customer service notifications
- Personal productivity reminders

## Tech Stack

- Telegram Bot API
- Python
- JSON
- Google Sheets (optional integration)

## Getting Started

### Clone Repository

```bash
git clone https://github.com/dimaslukman-rgb/Bot-telegram.git
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Configure Environment

Create a `.env` file:

```env
BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
CHAT_ID=YOUR_CHAT_ID
```

### Run

```bash
python main.py
```
